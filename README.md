# World taekwondo AI tournament predictor

#Overview

-Machine Learning project aiming to predict how a taekwondo tournaments fights will go by predicting the probability of one taekwondo fighter beating another using historical world taekwondo competition data. The final system will use the probabilities learnt to simulate tournament brackets and estimate each athletes probability of winning the tournament/making it to podium.

#Data sources

-Previous fight results will be collected from the official world taekwondo results pages, at results.worldtaekwondo.org
-Project will use Python to request and parse through tournament results pages, extract key relevant information such as scores, rounds, categories and winners, and convert the data into structured datasets for analysis and machine learning.

#Planned pipeline

-Python web data collection
-Pandas data cleaning
-Historical feature creation
-Machine learning fight prediction
-Monte Carlo tournament simulation
-Streamlit UI for application


#Tech stack

-Python, Pandas, NumPy, BeautifulSoup, scikit-learn, Streamlit
